# WSN 24/7 — бесплатный Telegram-бот спортивных новостей

Канал: https://t.me/wsn247

## Запуск
1. Создай **публичный** репозиторий на https://github.com/new, например `wsn247-news`.
2. Загрузи в него **с сохранением папок** файлы `bot.py`, `requirements.txt` и `.github/workflows/news.yml`. Через сайт GitHub можно загрузить папку проекта целиком (с компьютера) или создавать файлы с точными путями. Если загружаешь ZIP, предварительно распакуй — GitHub не распаковывает архивы автоматически.
3. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret**, создай секрет `TELEGRAM_BOT_TOKEN` со значением токена из @BotFather. **Не публикуй токен в исходном коде или чате.**
4. Открой **Settings → Actions → General → Workflow permissions** и выбери **Read and write permissions**, сохрани. Боту Telegram нужны админ-права на отправку сообщений в @wsn247.
5. **Actions → WSN 24/7 Sports News → Run workflow**. Первый запуск запоминает текущие новости, не публикуя их, чтобы не отправлять старый архив. Следующий запуск отправит новые статьи.
6. Расписание: каждые 10 минут; GitHub иногда задерживает или пропускает запланированные запуски, поэтому строгой гарантии 24/7 нет.

Новости из Google News и международных лент; часть заголовков может быть на английском. Бесплатный автоматический перевод без внешнего API не включён. Публикуются заголовки и ссылки, а не чужие полные статьи/фото.

## Безопасность и ограничения
Публичный репозиторий GitHub Actions со стандартным хостed runner бесплатен по текущим условиям GitHub, но исходный код публичный. Токен остаётся в секретах. Список прочитанных новостей в `seen.json` публичен. Не добавляй платные runners и платежный метод для этого проекта.

Охват ограничен подключёнными RSS-лентами, не абсолютно все новости мира. Возможны задержки и недоступность источников.
